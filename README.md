# Food Marketing Analytics Dashboard

## 📊 Project Overview

This project presents an interactive **Food Marketing Analytics Dashboard** built using **Microsoft Power BI**.

The dashboard analyzes customer behavior, marketing campaign performance, purchasing patterns, product spending, and RFM-based customer segmentation to support data-driven marketing analysis.

## 🎯 Project Objectives

* Analyze customer demographics and household characteristics
* Measure marketing campaign performance and customer responses
* Analyze customer spending across product categories
* Understand purchasing behavior across preferred channels
* Evaluate customer engagement and deal usage
* Perform RFM-based customer analysis and segmentation

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning & Transformation
* Data Modeling
* Data Visualization
* Microsoft Excel / CSV
